# Retail Sales Analysis Using SQL

## Project Overview

This project analyzes retail sales transaction data using SQL to extract meaningful business insights.

The analysis covers data cleaning, exploratory analysis, customer behavior, category performance, sales trends, high-value transactions, and time-based sales patterns.

The project was developed to demonstrate practical SQL skills relevant to Data Analyst and Data Engineering entry-level roles.

## Dataset

The dataset contains 2,000 retail transactions covering sales from 2022 to 2023.

### Dataset Schema

| Column | Description |
|---|---|
| `transactions_id` | Unique transaction identifier |
| `sale_date` | Date of the transaction |
| `sale_time` | Time of the transaction |
| `customer_id` | Unique customer identifier |
| `gender` | Customer gender |
| `age` | Customer age |
| `category` | Product category |
| `quantity` | Quantity of products sold |
| `price_per_unit` | Price of one unit |
| `cogs` | Cost of goods sold |
| `total_sale` | Total value of the transaction |

## 1. Database and Table Creation

A table named `retail_sales_t` is created to store the transaction data.

The table contains transaction, customer, product, cost, and sales information.

```sql
CREATE TABLE retail_sales_t(
    transactions_id INT PRIMARY KEY,
    sale_date DATE,
    sale_time TIME,
    customer_id INT,
    gender VARCHAR(15),
    age INT,
    category VARCHAR(15),
    quantity INT,
    price_per_unit FLOAT,
    cogs FLOAT,
    total_sale FLOAT
);
```

## 4. Business Analysis

The project addresses the following business questions using SQL.

### 1. Sales on a Specific Date

Retrieve all transactions made on `2022-11-05`.

### 2. Category-wise Total Sales

Calculate the total sales generated by each product category.

### 3. Average Customer Age for Beauty

Calculate the average age of customers who purchased products from the Beauty category.

### 4. High-Value Transactions

Identify transactions where the total sale amount is greater than 1,000.

### 5. Gender-wise Transactions by Category

Calculate the number of transactions made by each gender within each product category.

### 6. Best-Selling Month in Each Year

Calculate monthly average sales and identify the month with the highest average sales for each year.

### 7. Top 5 Customers

Identify the top five customers based on their total sales value.

### 8. Unique Customers by Category

Calculate the number of unique customers who purchased products from each category.

### 9. Sales by Time Shift

Classify transactions into:

- Morning
- Afternoon
- Evening

and calculate the number of orders in each shift.

### 10. Clothing Transactions in November 2022

Identify Clothing transactions from November 2022 where the quantity sold is at least 4.
